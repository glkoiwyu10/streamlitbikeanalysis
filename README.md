# **Project Bike Rental Analysis**

Dataset : https://www.kaggle.com/datasets/lakshmi25npathi/bike-sharing-dataset

This project use dataset day.csv only. This project is to explore the effect of weather and season combination
on the average daily bike rental between 2011-2012. It also explores the trend difference of average daily
bike rental between working days and non-working days for each month in 2012.

## Run this project
### 1. Clone repository
`git clone https://github.com/glkoiwyu10/streamlitbikeanalysis`
### 2. Install library
`pip install -r requriements.txt`
### 3. Locate dashboard
`cd dashboard`
### 4. Open streamlit
`streamlit run dashboard.py`
### Streamlit link : https://appbikeanalysis-ne86pkrjaqbhlzen29htke.streamlit.app/
